# Student E-Commerce Android App

## Overview
This project is a **student-built e-commerce mobile application** inspired by popular food and delivery platforms such as Talabat and Careem. The app demonstrates core e-commerce functionality, mobile UI/UX design, and backend integration using modern Android development tools.

It was developed as part of a university coursework project to practice real-world mobile application development concepts.

- **Language:** Kotlin  
- **IDE:** Android Studio  
- **Backend:** Firebase  
  - Firebase Authentication  
  - Firebase Realtime Database / Firestore  
- **UI:** XML layouts with Material Design components
